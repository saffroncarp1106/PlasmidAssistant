PlasmidAssistant — Windows x64

Keep PlasmidAssistant.exe, _internal, and protein_features.json together.
Run the executable; no Python or Ollama installation is needed.
Open a sequence > Find missing features > review/toggle suggestions > Save annotated copy.
Double-click a candidate to read its evidence. Open the saved copy in SnapGene.

The small bundled protein library works standalone. For DNA reference coverage,
place this folder inside a SnapGene installation with Plasmids/sampleData folders.
Online NCBI BLASTx is optional and asks before uploading your DNA.
Promoters and unknown genes are not guaranteed to be identified.
Delete this folder to uninstall. See README.md for details and limitations.
